# Vague quote

**Special:** The product maps cleanly to the product reference, but `usual Platts diesel screen`
is not specific enough to resolve a quotation code.

**Perturbations:** Dictation style, parties stated in prose, number words, a wrapped price sentence,
and `at a discount` rather than a negative sign.

**Failure caught:** Using product identity to guess the quotation, or nulling the entire pricing
object when only the quote code is unknown.
